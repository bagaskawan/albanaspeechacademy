# Antislop Audit 001 — Landing Page (front/components/home)

Mode: After. Scope: `front/components/home/**` (home page only), rendered via `HomePage` (`front/components/home/home-page.tsx`).

Method: grep for em dash across `components/home`, full visual scroll-through of the live dev server (desktop + mobile, 375×812), code read of flagged files. Two early "dead space" observations (bento gallery, benefit cards) were re-tested with slow/paced scrolling and did **not** reproduce — they were an artifact of fast synthetic scrolling outrunning the GSAP ScrollTrigger reveal animation (`front/lib/motion/scroll.ts`), not a real bug. Not included below (evidence-over-claims, C-5).

## HIGH — R-02, em dash in prose copy (Hard Gate)

These read as the AI "X — Y, Z" pattern the user flagged (screenshot: "Kelas terjadwal — kamu berlatih bersama peserta lain."). Fix: rewrite with comma/period, no dash.

1. `front/components/home/program-chapter.tsx:35` — "Kelas terjadwal — kamu berlatih bersama peserta lain." (the exact line in the user's screenshot)
2. `front/components/home/about-section.tsx:44` — "...agar tampil lebih percaya diri, komunikatif, dan profesional — lewat praktik langsung, bukan teori panjang."
3. `front/components/home/closing-section.tsx:31` — "Ceritakan situasinya — presentasi, memandu acara, atau pelatihan tim."
4. `front/components/home/trainer-section.tsx:51` — "...berbicara di depan audiens — di radio, panggung, ruang kelas, dan ruang rapat."
5. `front/components/home/testimonial-chapter.tsx:20` — description prop: "...bersama Albana — sebelum dan sesudah berdiri di depan orang." (not currently rendered — testimonial CMS data is empty, see #12 — but source text should still be fixed)

## MEDIUM — R-02, structural/decorative em dash

Same banned character, used as a design motif (chapter numbering, list bullet, "no data" placeholder) rather than prose. Lower narrative harm, but the rule has no exception for this, and it's one mechanical pattern to fix in one place for most of it.

6. Eyebrow pattern `"0X — Judul Bab"` repeats identically in 10 files: `benefit-band.tsx:26`, `program-chapter.tsx:20`, `inhouse-training-section.tsx:26`, `learning-method-chapter.tsx:42`, `legality-section.tsx:18`, `testimonial-chapter.tsx:13`, `trainer-section.tsx:45`, `registration-steps-section.tsx:22`, `schedule-section.tsx:41`, `about-section.tsx:39`. All consume the same `eyebrow` prop documented in `section-intro.tsx:5`. Fixing the separator convention there (e.g. swap `—` for `·` or `:`) fixes all 10 call sites at once.
7. `front/components/home/about-section.tsx:75` — `—` used as a literal bullet glyph before each trainer credential line.
8. `front/components/home/legality-section.tsx:50` — alt text: `` `${doc.title} — tampak belakang` ``.
9. `front/components/home/program-story-section.tsx:160` and `front/components/home/schedule-section.tsx:153` — `—` as the "no price yet" fallback glyph.

## LOW — Purpose-Gate / Quality Lock

10. `front/components/home/partner-marquee.tsx` — mobile logo marquee auto-scrolls continuously (`requestAnimationFrame` loop, no stop condition) and only pauses while the user's finger/pointer is actively down on it. R-39 requires a visible pause control for motion running longer than 5s; a touch-and-hold isn't one. Low severity (subtle logo strip, not primary content), but worth a visible pause/play affordance or a stop-after-one-loop behavior.
11. `front/components/home/inhouse-training-section.tsx:79-81` — the "Partner kami" heading is a bare centered label with no `eyebrow`/number and no supporting sentence, breaking the "0X — Judul Bab + description" pattern every other chapter uses. No stated reason for the exception (R-31).

## Content gap, not a code fix

12. Chapter 07 "Cerita peserta" (`testimonial-chapter.tsx`) renders nothing on the live page right now — `data.testimonials` is empty, so the section correctly hides itself (R-18/R-38 compliant: no fake testimonials shown). But that means the page currently has **zero social proof** from past participants, which is the single biggest persuasion gap for a paid training business. Not fixable by editing this code; needs real testimonial content added in the CMS.

## Optional craft suggestion (not a violation)

13. The real, named partner logos (Telkom Indonesia, BNI, bank bjb, KAI, Badan POM RI, PLN Pusharlis, Indomobil Group) are strong, verifiable social proof, but the block that shows them (`inhouse-training-section.tsx:77-105`) has no persuasive framing line, just "Partner kami". (Didn't recommend moving it directly under the hero — that would recreate the generic "Trusted By bar below hero" pattern R-05 forbids, even with real logos.)
