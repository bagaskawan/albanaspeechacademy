Pengiriman pendaftaran

Route memeriksa kiriman; RPC memeriksa ulang penawaran dan menyimpan pendaftaran serta tagihan dalam satu transaksi. Pembayaran tetap dicocokkan admin secara manual.

Hasil retry idempoten dapat kembali sebagai “received” tanpa baris baru. Lihat panduan arsitektur untuk kode status dan tindak lanjut DP.
