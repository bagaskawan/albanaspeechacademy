# Arsip dokumentasi

Dokumen di sini adalah catatan historis, rancangan yang telah digantikan, atau cadangan. Gunakan [README utama](../README.md) dan dokumen di folder luarnya sebagai acuan aktif.

- `legacy/`: brief, alur, serta rencana awal yang sudah berubah.
- `plans/`: rencana dan bukti pengerjaan terdahulu.
- `working-notes/`: spesifikasi dan rencana kerja historis.
- `design-backup/`: desain/kode cadangan.
- `admin/`, `requirements/`, `business/`, `proposals/`: referensi lama.
