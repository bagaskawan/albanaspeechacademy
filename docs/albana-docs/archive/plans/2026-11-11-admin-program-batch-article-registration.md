# Rencana implementasi admin, artikel, dan pendaftaran kelas Albana

**11 November 2026 · Siap untuk review produk dan implementasi bertahap**

Operator dapat membuka pendaftaran dari satu alur program dan batch. Member dapat memilih kelas, memeriksa nominal transfer, dan mengirim formulir dalam satu kunjungan; bukti transfer dikirim ke WhatsApp admin setelah tanda terima. Penulis dapat menyusun artikel dalam blok dan melihat hasil yang sama dengan halaman baca publik.

**Acuan isi pendaftaran** hanya [form 01 · Public Speaking Series](../../registration/forms/01-public-speaking-series.md) dan [form 02 · Basic to Advance Eksklusif](../../registration/forms/02-speaker-training.md). Keduanya mendeskripsikan Batch 9. Angka dan jadwal di bawah berlaku untuk penawaran tersebut. Gunakan data penawaran yang dikelola admin untuk batch berikutnya. Rencana ini mempertahankan pengiriman bukti transfer melalui WhatsApp seperti [rencana form sebelumnya](./legacy-step-02-registration-registration/registration-contract.md), tetapi rekening, nominal, dan instruksinya sekarang tampil di dalam wizard, bukan dikirim menyusul lewat chat.

**Urutan pengerjaan**

1. Langkah 1 → 2 → 3 untuk admin dan katalog.
2. Editor artikel (4) memakai hasil audit kontrak pada langkah 1 dan komponen dari langkah 2.
3. Intake pembayaran (5) memakai penawaran dari langkah 3; wizard member (6) memakai intake dari langkah 5.
4. Langkah 7 menguji ketiga alur dari halaman masuk yang sebenarnya.

Semua jalur file berawalan `front/` relatif terhadap root repo. Diagram alur ada di [archive/legacy/user-flow.md](../legacy/user-archive/legacy/user-flow.md).

### Istilah yang dipakai

| Istilah | Arti di rencana ini | Kode terkait |
|---|---|---|
| **Shell admin** | Kerangka tampilan yang membungkus semua halaman admin: topbar (logo, breadcrumb, tema, profil), sidebar navigasi, dan area konten. Mengubah shell berarti mengubah semua halaman admin sekaligus. | `front/app/(admin)/admin/layout.tsx` |
| **CmsCollectionClient** | Komponen generik satu tabel: daftar baris, dialog buat/edit, dan hapus. Halaman hanya mendefinisikan `fields`; komponen ini yang merender input lalu menulis ke Supabase. Dipakai halaman Batch, Trainer, dan Galeri; Artikel pindah ke halaman tulis/edit. | `front/components/admin/cms/CmsCollectionClient.tsx` |
| **Katalog** | Data publik yang dibaca pengunjung: academy, trainer, program + batch + sesi, galeri, dan testimoni. Dua program inti statis; batch ditulis admin. Dibaca beranda, detail program, dan register. Di sidebar admin, "KATALOG" juga nama grup menu (Program, Batch, Trainer, Artikel, Galeri). | `front/lib/server/catalog.ts` |
| **Batch** | Satu penawaran kelas berjadwal dari sebuah program (misalnya Batch 9): sesi, harga, DP, dan status buka. | tabel `batches`, `sessions` |
| **Varian** | Jenis formulir pada batch: `series`, `exclusive`, atau `bnsp`. | kolom `form_kind` |
| **Intake** | Jalur penerimaan kiriman formulir dari browser sampai tersimpan dan terbaca admin. | `POST /api/registrations`, `receive-registration.ts` |
| **RPC** | Fungsi database yang dipanggil lewat HTTP (`/rest/v1/rpc/...`), misalnya `receive_registration`. | `academyRequest` |
